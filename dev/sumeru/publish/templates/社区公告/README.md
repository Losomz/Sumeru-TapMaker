# 社区公告

更新公告以外的论坛帖子都存在这里，比如新手教程、常见问题、意见反馈、活动说明。一篇帖子一个文件，文件名就是帖子标题。更新公告放在 `docs/更新日志/`。

上线时必须有的两篇：「新手教程与常见问题」「玩法意见反馈」，模板在 `dev/sumeru/publish/templates/社区公告/`，新项目首次同步时会复制到本目录，直接把尖括号里的内容换成本游戏的。哪篇发到哪个子版块、哪篇挂到「活动与公告」，见 `dev/sumeru/publish/README.md`「上线必备帖子」。每篇结尾都带玩家交流群。

本目录不在资源根（`scripts/`、`assets/`）下，不会打进游戏包。发帖和挂到「活动与公告」的流程见 `dev/sumeru/publish/论坛公告.md`。

改了已发布的帖子，这里的稿件也要一起改，两边保持一致。
